# Расписание МАИ

Быстрое консольное приложение на Rust для актуального расписания учебных групп
МАИ. В комплекте:

- минималистичный полноэкранный TUI на
  [`terminalib`](https://github.com/acup1/terminalib);
- неинтерактивный текстовый и JSON-вывод;
- фильтры лабораторных и экзаменов;
- генерация текстовых файлов сразу для всех групп.

Источник данных — официальные страницы списка групп
`mai.ru/education/studies/schedule/groups.php` и JSON-файлы
`public.mai.ru/schedule/data/`. Проект не связан с администрацией МАИ.

Python-версия сохранена в ветке `python`.

## Запуск

Нужен Rust 1.85 или новее:

```bash
cargo run --release -- --help
cargo run --release -- raw М3О-101БВ-26
```

Установить бинарник локально:

```bash
cargo install --path .
mai-schedule --help
```

### Nix

```bash
nix run . -- --help
nix profile install .
```

После публикации:

```bash
nix run github:acup1/mai-schedule -- raw М3О-101БВ-26
```

## TUI

```bash
mai-schedule
mai-schedule tui М3О-101БВ-26
```

Без группы приложение последовательно предлагает выбрать институт, курс и
группу. Интерфейс использует framebuffer `terminalib`, корректно перерисовывается
после изменения размера терминала и поддерживает английскую и русскую
раскладки для буквенных команд.

- `←` / `→` — предыдущая и следующая неделя;
- `↑` / `↓` или `j` / `k` — прокрутка;
- `Shift+↑` / `Shift+↓`, `Page Up` / `Page Down` — прокрутка на страницу;
- `l` — лабораторные, `e` — экзамены, `w` — вернуться к выбранной неделе;
- `/` — поиск, `n` / `N` — следующее / предыдущее совпадение;
- `Esc` — закрыть поиск или вернуться на предыдущий экран;
- `q` — выйти из любого экрана, в том числе во время загрузки.

Сетевой таймаут по умолчанию — 2 секунды. Если МАИ не отвечает, TUI показывает
ошибку и повторяет загрузку автоматически, без дополнительного подтверждения.

По воскресеньям текущей считается уже следующая учебная неделя.

## Неинтерактивный режим

Текущая неделя:

```bash
mai-schedule raw М3О-101БВ-26
```

Конкретная неделя, дата, относительное смещение или диапазон:

```bash
mai-schedule raw М3О-101БВ-26 2026-W38
mai-schedule raw М3О-101БВ-26 current +1 +2
mai-schedule raw М3О-101БВ-26 2026-W38..2026-W42
mai-schedule raw М3О-101БВ-26 2026-09-14 --json
```

Фильтры по всему опубликованному расписанию:

```bash
mai-schedule raw М3О-101БВ-26 --labs
mai-schedule raw М3О-101БВ-26 --exams --json
```

Каталог:

```bash
mai-schedule groups
mai-schedule groups --institute 'Институт №3' --course 1
```

Таймаут сетевых запросов можно изменить глобальной опцией:

```bash
mai-schedule --timeout 10 raw М3О-101БВ-26
```

## Генерация файлов

```bash
mai-schedule generate --output dist --workers 8
```

Результат:

```text
dist/
├── groups.txt
└── М3О-101БВ-26/
    ├── current.txt
    ├── labs.txt
    ├── exams.txt
    ├── week-2026-W36.txt
    └── week-2026-W37.txt
```

Запись выполняется через временные файлы с атомарной заменой. `--workers`
принимает значения от 1 до 32.
